# Products API Assignment

Flask implementation of the DummyJSON products assignment.

## Requirements

- Python 3.13.12
- uv

## Setup

```bash
uv sync
```

## Run Locally

```bash
uv run flask --app run run
```

Then open the local Flask URL shown in the terminal.

## Current Status

Phase 1 project setup is complete. The app starts with a small Flask skeleton. Product retrieval, backend search, backend pagination, table rendering, and gallery interaction will be added in later phases.
